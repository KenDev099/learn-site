Node.js 核心 學習地圖

這門課把 Node.js 從「它是什麼」一路講到「能放心上線」。先弄懂 Node 怎麼執行你的程式、為什麼一個卡住的請求會拖垮所有人、檔案和位元組怎麼處理；接著不用任何框架，親手用 node:http 寫出咖啡店訂單 API：路由、驗證、錯誤格式、分頁、快取、串流、呼叫外部 API、PostgreSQL 連線池與交易、結構化 log、健康檢查與優雅關機、測試；最後是資深工程師要會的效能分析、記憶體洩漏、多核心擴展與安全。每個新名詞第一次出現都會解釋；用到 PostgreSQL 課或 TypeScript 課學過的東西，會標出是哪一課。學完再進 NestJS，你會清楚知道框架替你做了哪些事。

練習在你自己的電腦上做：第一次先在 learn/node/practice 執行 npm install；每一課的練習檔在 learn/node/practice/work/<課程代號>/，用 VS Code 編輯後，回到 learn/ 資料夾執行 node check.mjs node <課程代號>（例如 node check.mjs node 01-what-is-node），判分結果會顯示在課程頁上，每課另有頁面內的選擇題。需要 Node 24.16 以上（這台電腦是 24.22.1）。第 20、22、24、26 課會用 Docker Desktop 啟動 PostgreSQL，到時課程頁會一步一步帶你做。

練習在你自己的電腦上做。需要 Node.js 24（終端機輸入 node -v 確認）。第一次開始前，在 learn 資料夾執行：

cd node/practice && npm install

每一課的頁面會告訴你要改哪個檔案、要執行哪個指令；跑完測試切回課程頁就會自動判分。
