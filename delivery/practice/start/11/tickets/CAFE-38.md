# CAFE-38：下週一「早鳥半價」前的容量驗證

- 提出：店長（志明）
- 優先序：P1（活動已經公告，日期不能改）

下週一 7:00–9:00 全品項半價。上次「買一送一」那天，吧台的平板一直轉圈圈、看不到新單，客人在櫃台排到門口。這次預估是平常尖峰的 5 倍。

請工程在活動前確認：

1. 那天的流量下，系統撐不撐得住（目標：每個 API 的 p95 < 300 ms、錯誤率 < 1%）
2. 撐不住的話，是哪裡、為什麼，修好之後再確認一次

參考（平常的尖峰，早上 8 點）：每秒大約 4 個看菜單、0.8 個下單、2 個查訂單狀態；吧台三台平板，每台每秒拉一次廚房看板；廚房同時在做的單大約 40 張。
