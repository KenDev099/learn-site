# CAFE-50 釐清會議紀錄（2026-11-17）

參加：店長、吧台主管、你。

## 決定

1. 誰可以取消：下單的顧客本人（登入後）；店員也可以替顧客取消（同一個功能）。不是自己的訂單，就像那張訂單不存在。
2. 什麼時候可以取消：付好款（paid）、吧台還沒按「開始製作」之前。吧台按了開始製作（preparing）就不能取消，飲料已經在做了。
3. 退款：全額退回，用 CafePay 退款（2.1.0 的 SDK 已經合併進來了）。不管客人按幾次，只能退一次。
4. 點數：付款時送的點數要扣回來。點數紀錄只新增、不修改（CAFE-33 的規則）：寫一筆負的補償紀錄抵銷原本那一筆，不能刪掉原本那一筆。
5. 取餐時段：有預約時段的訂單取消之後，那個時段要空出一個名額給別人。
6. 客人按取消和吧台按開始製作幾乎同時發生時：只能有一個成功。取消成功，吧台就不能開始做；吧台先開始，客人就取消不了。
7. 已經取消的訂單再按一次取消：不要顯示錯誤，直接告訴客人「已取消」，也不要再退一次款。

## 畫面（訂單頁）

- 只有可以取消的訂單顯示「取消訂單」按鈕。
- 按下去先跳出確認視窗，寫清楚會全額退款；客人按「確定取消」才真的取消，按「先不要」就關掉。
- 取消成功後顯示「已取消，款項將退回」，按鈕不再出現。
- 取消不了（例如吧台剛好開始做了）：顯示原因，按鈕不再出現。

## 先不做（之後另開需求單）

- 還沒付款（pending）的訂單：不能取消，30 分鐘沒付款由系統自動作廢（CAFE-51）
- 部分退款（只退其中一杯）
- 店員在 POS 上的退款流程
