## A 總報酬的組成 {span=2}
| 組成 | 怎麼算 | 性質 |
|---|---|---|
| 固定現金 | 月薪 ×（12＋保障月數） | ok 保證；「年終通常 2 個月」不是保障 |
| 變動現金 | 月薪 × 預估獎金月數 | warn 預估 |
| 股票 | 總價值 ÷ 歸屬年數 | warn 預估；有 cliff 時待不滿拿不到，選擇權可能歸零 |
| 簽約金 | 一次性金額 | warn 只算第一年，常附退回條款 |
| 勞退提繳 | 約月薪 × 提繳率 × 12 | 另列，進個人專戶，不是現金 |

```kv cols=2
第一年總報酬: 固定＋變動＋股票＋簽約金
穩定年度總報酬: 固定＋變動＋股票
```
一律用稅前數字；兩個總報酬都不含勞退。福利列在旁邊參考，不加進總報酬。

## B 三份 offer 的示範
這課的虛構 offer：

| | A 連鎖咖啡品牌 | B 外商點餐平台 | C 新創 |
|---|---|---|---|
| 第一年總報酬 | 112 萬 | 157 萬 | 123 萬 |
| 其中保證 | 112 萬 | 84 萬 | 108 萬 |

B 的穩定年度 142 萬，但其中 58 萬是預估、15 萬只發一次，保證的現金比 A 少 28 萬；C 的選擇權當成 0 時，穩定年度從 123 萬變 108 萬。

```callout warn 用悲觀假設再算一次
獎金只算保證部分、股票打六折、選擇權當 0。悲觀版本也能接受的 offer 才是穩的；贏在不確定數字上的，就去問過去實際發了幾個月、歸屬時程與 cliff、簽約金退回條款。
```

## C 談薪：時機、說法、界線 {span=2}
```flow LR
[拿到書面 offer] -> [感謝與意願] -> [期望] -> [依據] -> *[具體請求]
```
依據：職缺公布的範圍、市場資料（看範圍不看單一數字；來源如 GoodJob 職場透明化運動、104 薪資情報、同類職缺 JD、信任的同業，匿名數字無法查證，要多方並排）、職責範圍、你現職的穩定年度總報酬。能談的還有職級（影響最久）、簽約金、保障月數、到職日；一次提一兩個。

| 說法 | 例子 |
|---|---|
| ok 好的 | 有依據的數字與具體請求；誠實請求延長回覆期限並給具體日期 |
| warn 有風險 | 「多少都可以」、電話裡當場答應、沒依據的數字、主動先說目前薪資 |
| no 不誠實 | 捏造其他 offer、謊報目前薪資：被發現常見的結果是撤回 offer |

錢之外看職級、範圍、主管與團隊、on-call 與技術債、成長、通勤；用加權表，權重是自己的。問團隊時用「去年幾次」這種具體問題。

## D 到職與契約的底線
截至 2026 年 11 月；本課不是法律意見，個案問專業人士。

| 規則 | 內容 |
|---|---|
| 最低工資 | 2026 年起每月 29,500 元、每小時 196 元；已決議 2027 年起調為每月 30,900 元、每小時 205 元，以行政院核定公告為準 |
| 薪資揭露 | 經常性薪資未達 4 萬元的職缺，雇主要公開揭示或告知薪資範圍；勞動部正在研議調整門檻 |
| 離職預告 | 不定期契約：未滿 3 個月 0 日、未滿 1 年 10 日、未滿 3 年 20 日、3 年以上 30 日 |
| 特休 | 契約終止時未休完的要發給工資 |
| 勞退 | 雇主每月提繳不得低於工資 6%，進個人專戶 |
| 競業禁止 | 四個要件缺一項約定無效；期間最長 2 年，超過的縮短為 2 年 |
| 試用期 | 勞動部見解：仍要有法定事由、預告與資遣費；部分法院判決見解不同 |

順序：書面 offer → 確認條件 → 書面接受 → 才向現職提離職。

## E 資深不是年資，是範圍 {span=2}
```flow LR
[junior：自己的任務] -> [mid：一個功能] -> [senior：一個團隊的系統] -> *[staff：跨團隊]
```
| 層級 | 菜單快取這件事 | 誰決定要做什麼 |
|---|---|---|
| junior | 照 ticket 加上 Redis 快取、寫測試 | 別人 |
| mid | 自己決定快取方式、TTL、失效做法 | 需求別人給，做法自己決定 |
| senior | 從監控發現負載偏高、寫設計文件、拆工作給同事 | 自己，從發現問題開始 |
| staff | 推動三個團隊採用共同的快取規範 | 自己，還要說服其他團隊 |

判斷時問：要做什麼是誰決定的？做完影響到誰？職級名稱各公司不同，以公司的職級說明為準。staff 是個人貢獻者路線，帶人是另一條管理職路線。

## F 主導、成果紀錄、影響力
- 主導：自己發現沒人做的事，寫成有問題（數字）、範圍、做法與成本、成功指標的提案；指標在動手前寫下。
- 成果紀錄每週 5 分鐘：日期、做了什麼、影響、誰受益、證據連結、能力。少了影響、受益者或證據就是弱紀錄，要回頭補。每季依能力分組，對照職級說明找缺口。
- 沒有職權的影響力：一頁提案 → 事前溝通 → 小範圍試點 → 用數字回報。遇到反對先理解對方的成本，替對方降低成本。
- Learn 之後：用職缺和團隊需要決定學什麼，每季一個主題、一定要有產出。

## G 1:1 與容量
```kv cols=1
1:1 議程順序: 阻礙 → 需要的決定 → 回饋 → 職涯；進度會前寫成文字
升遷: 問清楚升遷標準、主動回報風險、替主管準備升遷文件的材料
不同意時: 決定前用資料表達、確認被記錄；決定後全力執行並約檢查點
```
| 這課的示範 | 小時 |
|---|---|
| 每週工時 | 40 |
| 扣固定會議 10 | 30 |
| 扣打斷 20% | 24 |
| 值班週打 7 折 | 16.8 |
| 只承諾 80% | 13 |

沒值班的週約 19 小時。容量滿了，給選項（延後、縮小範圍、換人接手），讓主管決定優先序。出現過勞的早期訊號，先在 1:1 談工作量，需要時找專業協助。
