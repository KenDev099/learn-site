面試與職涯 學習地圖

這門課教「找到資深職缺、拿到 offer、進去之後繼續往上長」這整段過程。前面的課教你把咖啡店點餐系統做出來；這門課教你怎麼讓別人在 30 秒的履歷掃描、45 分鐘的面試裡相信你做得出來，以及進公司之後怎麼被認定為資深。內容從招聘流程每一關在檢查什麼開始，依序是履歷、作品集與 GitHub、行為面試與故事庫、現場寫程式、帶回家作業、系統設計面試、評估 offer 與談薪，最後是升到資深／staff 的期待、和主管合作、避免過勞與學完 Learn 之後的學習計畫。

練習在頁面裡的 TypeScript 練習區完成。軟技能一律寫成有型別的結構化資料，讓隱藏測試可以判分：把履歷句子寫成 { action, scope, result: { metric, value } }，模糊的「負責」「參與」會被擋下；STAR 故事少了結果或全是「我們」會判錯；系統設計面試計畫要有每個階段、算得出來的數字和取捨；offer 計算機要把月薪、保障年終、股票歸屬與簽約金換算成可以比較的年度總報酬。每課另有至少 3 題針對常見誤解的選擇題。

這門課假設你已經學過（或正在學）Learn 的技術課：用到時會寫出是哪一課並附上連結，不重教。課程以台灣就業市場為背景（104、LinkedIn、外商與本土公司的流程差異、勞基法相關的幾個硬規則），談薪與 offer 只教怎麼算清楚、怎麼問，不提供個人化的財務建議。
