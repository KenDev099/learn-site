React：給會 Vue 的人 學習地圖

你每天寫 Vue 3，這門課帶你用已經會的東西學 React。兩者解決同一個問題，心智模型卻不同：Vue 追蹤你讀了哪些響應式資料，資料變了只更新用到它的地方；React 把元件當成「state 進、畫面出」的函式，state 變了就重新呼叫整個函式。前四課先把這個模型建立起來，之後每個主題都對照 Vue 的對應物：ref 與 useState、watch 與 useEffect、composables 與自訂 hook、slots 與 children、provide/inject 與 Context、Pinia 與 Zustand。

後半段是資深工程師每天要做的判斷：狀態放哪裡、伺服器資料怎麼快取與失效、樂觀更新失敗怎麼回復、什麼時候才需要 memo、React Compiler 幫你做了什麼、什麼時候需要 SSR 或 Server Components、測試怎麼寫才擋得住錯。最後用咖啡店線上點餐前端把全部串起來，和 Vue 課的期末專題是同一份需求。

第 1 課的練習直接在頁面上寫；其他練習在你自己的電腦上做，用 Vitest、Testing Library 與 happy-dom 跑隱藏測試（第 2 課會帶你把環境裝好）。這門課接在「JS、非同步與 TypeScript」與「Vue 3 深入與前端架構」之後；沒學過 Vue 課也能跟上，對照的部分會說明 Vue 那邊是怎麼做的。

版本以 2026 年 11 月為準：React 19.3.1、React Router 8.5.1、TanStack Query 5.106.1、Zustand 5.0.16、Vite 8.3.5、Vitest 5.0.5、@testing-library/react 16.3.3、happy-dom 21.0.4。
