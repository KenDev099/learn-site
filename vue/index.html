Vue 3 深入與前端架構 學習地圖

這門課從響應式的原理開始：先用 Proxy 自己做一個迷你版的 Vue 響應式系統，再回到真正的 Vue，弄懂 ref、computed、watch、nextTick 背後的規則；接著拆解元件怎麼渲染、怎麼溝通、怎麼重用、怎麼寫型別。後半段是資深工程師每天要做的判斷：狀態放哪裡、API 層怎麼設計、非同步資料與表單怎麼處理、前端權限的界線在哪、錯誤怎麼監控、測試怎麼寫才擋得住錯、效能怎麼量、什麼時候需要 SSR、專案怎麼切模組。最後用一個咖啡店線上點餐前端把全部串起來。

練習分兩種。迷你響應式系統、API 層、權限規則這類純邏輯，直接在頁面裡寫、按下檢查就判分；真正的 Vue 元件、Pinia、vue-router，則在你自己的電腦上寫，用 Vitest、Vue Test Utils 與 happy-dom 跑隱藏測試（第 4 課會帶你把環境裝好）。這門課接在「JS、非同步與 TypeScript」之後，不需要先學後端課程；用到後端的觀念（HTTP、權限、冪等）會在課內說明，並標出哪門課會深入。

版本以 2026 年 10 月為準：Vue 3.5.44、Pinia 4.1.0、vue-router 5.4.0、Vite 8.3.5、Vitest 5.0.5、@vue/test-utils 2.5.1、happy-dom 21.0.4。Vue 3.6 目前還是 RC（候選版），課程不使用。

前 3 課和部分練習直接在頁面上寫；其他練習在你自己的電腦上做，需要 Node.js 24。第一次開始前，在 learn 資料夾執行：
