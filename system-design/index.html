Learn · 資深能力

系統設計與資深工程實踐 學習地圖

這門課把前面學過的後端能力放大到「一整個系統」。咖啡店推出線上點餐 App 之後，流量、資料、外部依賴和團隊人數都會變多：一台伺服器不夠、資料庫被讀爆、金流偶爾變慢、同一張訂單被扣兩次款。課程從需求、估算與效能指標開始，依序學擴展（負載平衡、快取、複寫、分片）、可靠性模式（逾時、重試、冪等、限流、斷路器、佇列、saga、分散式鎖）、架構（單體與微服務、事件、即時推送），最後練資深工程師每天在做的事：寫設計文件與 ADR、不停機地演進系統、做 code review、管理技術債、除錯與處理線上事故。期末專題把整套機制組成一條可靠的下單路徑，並寫成一份設計文件。

練習在頁面裡的 TypeScript 練習區完成。你會親手實作這些機制本身：延遲與可用性的計算、百分位數與 histogram、P2C 負載平衡、快取的 single-flight 與 lease、一致性雜湊、指數退避、冪等的復原點、token bucket、斷路器、visibility timeout 佇列、outbox relay、saga 補償、fencing token、SSE 續傳……時間、亂數、計時器與網路一律由測試注入，所以每次結果都一樣；隱藏測試會模擬並發、當機、重送與亂序，擋下「看起來能動、上線會出事」的寫法。判斷力用結構化的練習驗證：替 PR 標出阻擋合併的問題、修正一份設計文件、替技術債排優先順序、從 trace 找出根因。每課另有至少 3 題針對常見誤解的選擇題。這門課假設你學完 PostgreSQL、TypeScript、Node、NestJS、認證與部署課，用到時都會寫出是哪一課並附上連結；全課程沿用咖啡店的資料。

練習直接在頁面上寫 TypeScript：自己實作快取、限流、重試、冪等、熔斷等機制，隱藏測試用假時鐘和固定亂數檢查每個邊界情況。
