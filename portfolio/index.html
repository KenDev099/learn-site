作品專案：從小專案到多租戶 SaaS 後台

前面的期末專題都是「在給好的咖啡店程式上修補或加功能」。這門課從空資料夾開始：你自己決定資料夾結構、模組怎麼切、取捨寫成 ADR（架構決策紀錄），程式放在你自己的 GitHub repo，最後是一份可以放進履歷、面試時講得出每個決定的作品。課文不重教觀念，每個觀念一句回顧並連回教過的那一課，篇幅花在「在自己的專案裡怎麼做」「零件接在一起時才出現的問題」與「取捨」。

階段 A（第 1～5 課）用一個小題目「活動報名 API」走完一次完整流程：需求、schema、分層 API、測試、Docker、CI 與 README。學完 NestJS 課就可以開始。階段 B（第 6～19 課）做多租戶 SaaS 後台：租戶隔離（Prisma extension＋PostgreSQL RLS）、帳號與 token、成員與角色、稽核、檔案、背景工作、方案上限、OpenAPI、可觀測性、部署與資安檢查；業務題目自選（客服工單、預約排程、進銷存）。階段 B 要先學完 認證、權限與資安、部署與維運、系統設計。

判分方式：每一課有幾題本機驗收，你在自己的專案啟動 API，在 learn 資料夾執行 node check.mjs nestjs pfNN，測試對你的 API 打 HTTP（少數題目讀 repo 的檔案或用資料庫唯讀檢查）。測試只照公開的 API 契約檢查（小專案契約、SaaS 契約），不管你的程式怎麼寫。課程的 PostgreSQL、Redis、Mailpit 借用 NestJS 課的練習環境（learn/nestjs/practice 的 docker compose up -d --wait）。
