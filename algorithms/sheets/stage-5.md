遞迴先寫終止條件，再相信小一號的問題已經會算。樹題照這個範本：先想空樹，再用左右子樹的答案組合出自己的答案。[回 演算法 學習地圖](../index.html)

## A 寫遞迴的三個問題
```kv cols=1
這個函式在算什麼: 用一句話寫下來，例如 `orders(n)` 回傳 n 位顧客的排法數
最小的情況: 寫成終止條件，放在第一行
這一層怎麼組合: 假設小一號的問題已經會算，只想這一層；每次呼叫都要往終止條件靠近一步
```
- 每次呼叫在呼叫堆疊放一個堆疊框，回傳時拿掉。空間是最深的層數。
- 太深丟 `RangeError`，上限依引擎而定；V8 沒有尾呼叫最佳化。
- 巢狀資料（分類、留言、巢狀陣列）用遞迴最自然；深度可能很大時改用迴圈。

## B Fibonacci：從遞迴到迴圈
| 寫法 | 時間 | 空間 |
|---|---|---|
| 照定義遞迴 | no O(1.6ⁿ) | O(n)（堆疊） |
| 遞迴 + Map 記憶化 | ok O(n) | O(n)（Map + 堆疊） |
| 由下往上的迴圈 | ok O(n) | ok O(1) |

時間看總共呼叫幾次。Map 要放在外層，讓所有遞迴呼叫共用；查表寫 `saved !== undefined`，因為 f(0) 是 0。

```callout warn 2⁵³ − 1 之後不精確
number 的精確整數只到 2⁵³ − 1，超過不會報錯。fib(79) 用 number 算已經差 1；要精確就用 BigInt。
```

## C 三種 DFS 走訪 {span=2}
```tree
1 | 根
  2
    4 | 左
    5 | 右
      7 | 左
  3
    6 | 右
```
| 名稱 | 處理自己的時機 | 這棵樹 |
|---|---|---|
| 前序 | 自己 → 左 → 右 | 1 2 4 5 7 3 6 |
| 中序 | 左 → 自己 → 右 | 4 2 7 5 1 3 6 |
| 後序 | 左 → 右 → 自己 | 4 7 5 2 6 3 1 |

三種都先左後右，走過的路徑一樣，只差在什麼時候記下自己。需要子樹的結果才能算自己時用後序。

## D 用子樹的答案組合出自己的答案
| 題目 | 空樹 | 這一層 |
|---|---|---|
| 菜單有幾層 | 0 | `1 + Math.max(l, r)` |
| 鏡像翻轉 | `null` | 先存好原本的左子樹，再交換 |
| 直徑 | 0 | 回傳高度給上一層，用閉包更新 `best = max(best, l + r)` |
| 最近共同祖先 | `null` | 自己是 p 或 q 就回傳自己；左右都非 null 時自己就是答案 |

直徑一次走訪做到 O(n)；每個節點都重算高度最壞 O(n²)。最近共同祖先比的是節點參考。遞迴 DFS 時間 O(n)、空間 O(h)：平衡時 O(log n)，歪斜時 O(n)。

## E BFS：用佇列一層一層走 {span=2}
```flow LR
(根放進佇列) -> {head < queue.length?}
{head < queue.length?} -> [記下 size = queue.length − head]: 是
{head < queue.length?} -> [結束]: 否
[記下 size = queue.length − head] -> [取出這一層的 size 個]
[取出這一層的 size 個] -> [非 null 的子節點放到尾端]
[非 null 的子節點放到尾端] -> {head < queue.length?}
```
- 佇列用 head 索引：`const node = queue[head++]`，不用 `shift`。
- 每一層第 `size − 1` 個是這層最右邊的。
- 最淺的葉節點：BFS 遇到第一個左右都是 null 的節點就回傳。DFS 把 max 換成 min 會錯：只有一邊子樹的節點不是葉。

## F 怎麼選工具
| 題目的特徵 | 用 | 代價 |
|---|---|---|
| 最近的、成對抵消、可撤銷 | 堆疊 | O(n)、空間 O(n) |
| 層、最近、最少幾步 | 佇列、BFS | 空間是最寬那一層 |
| 要先知道子樹的答案、路徑 | DFS | 空間是樹的高度 |
| 樹有大小順序：找值、插入、第 k 小 | BST | O(h)，歪斜時 O(n) |
| 串列上插入、刪除、反轉 | 鏈結串列的指標操作 | O(n)、O(1) 空間 |
| 串列的中間、有沒有環、倒數第 k 個 | 快慢指標 | O(n)、O(1) 空間 |

## G 二元搜尋樹：形狀決定速度 {span=2}
| 操作 | 排好序的陣列 | 平衡的 BST | 歪斜的 BST |
|---|---|---|---|
| 找一個值 | O(log n) | ok O(log n) | no O(n) |
| 插入、刪除 | O(n) | ok O(log n) | no O(n) |
| 依序列出全部 | O(n) | O(n)（中序） | O(n) |

- 規則：整個左子樹都比自己小、整個右子樹都比自己大；中序走訪由小到大。
- 搜尋：小往左、大往右，走到 `null` 就是不存在；迴圈寫，O(h) 時間、O(1) 空間。
- 插入：走到空位放新節點；遞迴寫法回傳子樹的新根，呼叫的人接回 `left`／`right`。
- 普通 BST 不會自己平衡，遞增插入會變成一條線。正式環境用 AVL、紅黑樹或 B-tree；JavaScript 沒有內建的平衡樹。

## H 驗證 BST 與第 k 小
```flow TB
(根：範圍 -Infinity 到 Infinity) -> [往左：上界收緊成自己的值]
(根：範圍 -Infinity 到 Infinity) -> [往右：下界收緊成自己的值]
```
- 只比父子會錯：上下界來自所有祖先。也可以檢查中序嚴格遞增。
- 初始值用 `-Infinity`／`Infinity`，不用 0 或 `Number.MIN_VALUE`。
- 重複值的規則要先問。
- 第 k 小：用堆疊的迴圈中序走訪，取出第 k 個就停，O(h + k)。
