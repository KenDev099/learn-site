面試不會告訴你用哪個技巧。從關鍵字和資料量限制推出第一個猜測，用小例子確認，全程把想法說出來。[回 演算法 學習地圖](../index.html)

## A 面試官在看什麼
| 面向 | 面試官看的事 | 只交程式碼時 |
|---|---|---|
| 溝通 | 先確認題意、講得出方向、聽得懂提示 | no 全部看不到 |
| 解題 | 從暴力解出發、找出重複的工作、選對資料結構 | warn 看不到怎麼想到的 |
| 程式 | 正確、命名清楚、結構乾淨 | ok 看得到 |
| 驗證 | 主動測試、找到自己的錯、說出複雜度 | warn 看不到空跑與邊界檢查 |

寫出正確的暴力解、說清楚為什麼慢、提出改進方向，常常比沉默地寫出最佳解、卻答不出複雜度的人分數高。

## B 45 分鐘怎麼分配 {span=2}
```timeline h
5 分 | 釐清與舉例 | 重述題目、問輸入範圍與邊界、舉一個例子對答案
8 分 | 思路與複雜度 | 暴力解與 Big-O、為什麼不夠、改進後的 Big-O；面試官同意再寫
*20 分 | 寫程式 | 邊寫邊說，先寫主流程
7 分 | 測試與修正 | 手動執行小例子、檢查邊界、修 bug
5 分 | 總結與問答 | 最終複雜度、取捨、正式環境還會加什麼
```
時間是參考值，重點是順序。前 13 分鐘還沒寫程式是正常的。整場都把正在想的事說出來，面試官才能在你走偏時及早提醒。

## C 開場要問的事
| 問題 | 為什麼會改變寫法 |
|---|---|
| 輸入會不會是空的？ | 空陣列要先處理，`arr[0]` 是 `undefined` |
| 找不到時回傳什麼？索引還是值？ | 回傳格式錯就全錯 |
| 輸入多大？ | 決定需要的複雜度 |
| 有沒有重複的值？ | 用 Set 還是 Map 計數、相等算不算 |
| 會不會有負數或 0？ | 負數讓滑動視窗失效，0 讓除法不能用 |
| 已經排序了嗎？ | 排序過可以用雙指標或二分搜尋 |
| 可以修改輸入嗎？ | 原地排序會改到呼叫端的資料 |

問完用一個有代表性的小例子跟面試官確認題意，之後也拿它空跑。

## D 示範：撞單有幾組 {span=2}
```sequence
participants: 面試者, 面試官
面試者 -> 面試官: 陣列可能是空的嗎？最多幾筆？
面試官 --> 面試者: 可以是空的，回傳 0；最多 10⁵ 筆
面試者 -> 面試官: 例子 LAT AME LAT LAT，答案 3，對嗎？
面試者 -> 面試官: 暴力解兩層迴圈 O(n²)，10⁵ 筆太慢
面試者 -> 面試官: 改進：Map 記每款到目前出現幾次，第 j 筆新增的組數就是前面同款的筆數
面試者 -> 面試官: 空跑例子，檢查空的、全部不同、全部一樣
面試者 -> 面試官: 時間 O(n)，空間 O(不同代碼的數量)
```
全部一樣時答案是 n(n − 1) / 2，n = 10⁵ 還在 `Number.MAX_SAFE_INTEGER` 以內：「數字會不會太大」是資深的人會主動補的檢查。

## E 從題目的樣子選技巧 {span=2}
| 題目的樣子 | 先想到 |
|---|---|
| 配對、看過沒、計數、分組 | 雜湊表 |
| 已排序，找兩個數或去重 | 雙指標 |
| 已排序，或答案有分界 | 二分搜尋（包含對答案二分） |
| 連續的一段，條件隨長度單調變化 | 滑動視窗 |
| 連續一段的總和、區間查詢 | 前綴和 |
| 括號配對、成對抵銷；下一個更大／更小 | 堆疊、單調堆疊 |
| 樹的高度、路徑；網格上的連通區域 | DFS |
| 最少幾步、逐層、同時往外擴散 | BFS |
| 前 k 個、一直要拿目前最小／最大 | heap |
| 列出所有方案，n 很小 | 回溯 |
| 最多、最少、有幾種方法，子問題會重疊 | 動態規劃 |
| 先做 A 才能做 B | 拓撲排序 |

| n 的上限 | 需要的複雜度 |
|---|---|
| ≤ 10～20 | O(2ⁿ)、O(n!) 也可以 |
| ≤ 500 | O(n³) |
| ≤ 10⁴ | O(n²) |
| ≤ 10⁵～10⁶ | O(n log n) 或 O(n) |
| 更大，或值的範圍到 10⁹ | O(log n) 或對值域二分 |

兩張表一起看，給出第一個猜測，再用小例子手算確認。

## F 卡住的時候
```flow TB
(卡住) -> [說出卡在哪]
[說出卡在哪] -> [換更小的例子手算，看手在重複做什麼]
[換更小的例子手算，看手在重複做什麼] -> [先交出正確的暴力解]
[先交出正確的暴力解] -> [對照技巧表挑兩個候選]
[對照技巧表挑兩個候選] -> *接受提示，複述後再動手
```
寫完要空跑、檢查邊界、說出時間與空間複雜度。最容易出事的是差一：寫到索引時說出為什麼是 `<` 或 `<=`。
