把迴圈裡的線性查找換成 Set／Map，O(n²) 就變成 O(n)，代價是 O(n) 的額外空間。重點在 Map 裡存什麼、鍵怎麼選。[回 演算法 學習地圖](../index.html)

## A 雜湊表怎麼做到平均 O(1) {span=2}
```flow LR
(鍵 林志豪) -> [雜湊函式]: 同樣的鍵一定算出同樣的數字
[雜湊函式] -> [桶號 = 數字除以桶數的餘數]
[桶號 = 數字除以桶數的餘數] -> [打開那一格]
[打開那一格] -> {桶裡不只一個?}
{桶裡不只一個?} -> *找到: 只有一個
{桶裡不只一個?} -> [逐一比較鍵]: 碰撞
[逐一比較鍵] -> *找到
```
- 加入、查詢、刪除平均 O(1)；大量的鍵撞進同一個桶時會退化成逐一比較。
- ECMAScript 規格只要求平均存取時間低於線性，面試時說「平均 O(1)」最精確。
- 雜湊表要另外的記憶體存鍵和值，O(n²) → O(n) 的代價通常是 O(n) 額外空間。

## B Set、Map 還是一般物件
| 容器 | 回答什麼 | 什麼時候用 |
|---|---|---|
| `Set` | 有沒有 | ok 去重、查看過沒 |
| `Map` | 鍵 → 值 | ok 計數、記位置；鍵來自資料 |
| 一般物件 `{}` | 固定的欄位 | warn 只在形狀固定、鍵是寫死的時候 |

計數：`map.set(k, (map.get(k) ?? 0) + 1)`。物件的鍵會變字串，還會撞到原型上的 `constructor`、`toString`。

```callout info 陣列和物件當鍵比的是參考
Map／Set 用 SameValueZero 比較鍵。要依內容查，組成有分隔符號的字串鍵，例如 ``${row},${col}``。
```

## C Two Sum：內迴圈在找補數
| 寫法 | 時間 | 額外空間 |
|---|---|---|
| 暴力解：每一組都試 | no O(n²)，n(n − 1) / 2 次 | O(1) |
| Map 記「值 → 索引」，一次走完 | ok O(n) | warn O(n) |
| 已排序時用雙指標（第 7 課） | O(n) | ok O(1) |

暴力解的內迴圈一直在問「有沒有一個值等於 `target − x`」，這是查找。沒排好序又要原本的索引時用 Map：排序會打亂索引。

## D 先查再存：禮券 190 元 {span=2}
```sequence
participants: 走訪, Map
走訪 -> Map: i=0 價格 90，查 100
Map --> 走訪: 沒有，存 90 → 0
走訪 -> Map: i=1 價格 70，查 120
Map --> 走訪: 沒有，存 70 → 1
走訪 -> Map: i=2 價格 110，查 80
Map --> 走訪: 沒有，存 110 → 2
走訪 -> Map: i=3 價格 80，查 110
Map --> 走訪: 有，索引 2 → 回傳 [2, 3]
```
這課的示範資料：價格 `[90, 70, 110, 80]`、禮券 190。Map 裡只放左邊走過的飲料，所以不會用到自己；`[80, 80]` 這種重複的值也能配對。

```callout warn 索引 0 不是「沒查到」
判斷寫 `j !== undefined`，不寫 `if (j)`。先存再查時，禮券剛好是某一杯的兩倍，同一杯就會用兩次，例如回傳 `[0, 0]`。
```

## E 變化題只換 Map 的值
| 題目問 | Map 的鍵 → 值 | 走到 x 時 |
|---|---|---|
| 哪兩個索引 | 價格 → 索引 | 查到補數就回傳 |
| 總共有幾組 | 價格 → 出現次數 | 加上補數出現過幾次，再把 x 的次數 + 1 |
| k 筆之內又點了 | 顧客編號 → 最近一次的索引 | 距離 ≤ k 就是 true；不管有沒有查到都更新 |

## F 分組：同一組要算出同一個簽名 {span=2}
```flow LR
['CAL'] -> [簽名 ACL]: 排序後的字母
['LAC'] -> [簽名 ACL]
[簽名 ACL] -> [(Map 簽名 → 單的陣列)]: 先 get，沒有就放新陣列
```
| 鍵 | 結果 |
|---|---|
| 排序後的字串 | ok 同組同鍵，不同組不同鍵 |
| 用分隔符號串起來的計數 | ok 同上 |
| Set | no 丟掉次數，`'AAB'` 和 `'ABB'` 併成一組 |
| 加總 | no 加起來一樣就併成一組 |
| 沒有分隔符號的串接 | no 顧客 1 商品 23 和顧客 12 商品 3 都是 `'123'` |

ES2024 的 `Map.groupBy` 回傳 Map，`Object.groupBy` 回傳原型是 null 的物件，組內都放整個元素。鍵設計錯時程式不會報錯，結果默默錯。

## G 最長的連續來店天數
| 寫法 | 時間 | 要注意 |
|---|---|---|
| 排序後往下數 | O(n log n) | 給 `(a, b) => a - b`；重複的天數跳過，不歸零 |
| Set，每天都往上數 | no O(n²) | 同一段被數很多次 |
| Set，只從起點往上數 | ok O(n) | 起點是 x − 1 不在 Set 裡；for 走 Set，不走原陣列 |

每個數最多被往上數一次，所以 for 裡的 while 加起來最多 n 次。

## H 內迴圈在問什麼，就用什麼
| 重複的工作在問 | 用 |
|---|---|
| 這個看過沒？ | Set |
| 這個出現幾次？ | Map 計數（頻率表） |
| 這個在哪裡？ | Map 記索引 |
| 這些算不算同一組？ | Map 到清單，鍵是簽名 |

不提示技巧的題目，先寫暴力解，再看內迴圈在問哪一種。
