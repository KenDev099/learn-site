演算法與資料結構：面試基礎 學習地圖

這門課給「會寫 JavaScript／TypeScript，但一看到 LeetCode 第 1 題 Two Sum 就卡住」的人。目標不是競賽，也不是證明定理，而是學會面試常見的基本資料結構與演算法：陣列、雜湊表、雙指標、排序、二分搜尋、滑動視窗、前綴和、堆疊與佇列、鏈結串列、遞迴、樹、heap、圖、回溯、貪婪與動態規劃，最後用一堂模擬面試把它們串起來。每個名詞第一次出現都會解釋；用到 TypeScript 課教過的東西（值與參考、Map／Set、迭代器、泛型）會寫出是哪一課並附上連結。

每一題都照同一套步驟走：重述題目、用小例子手算、先寫暴力解、找出重複做的工作、改進、檢查邊界情況、說出時間與空間複雜度。卡住不是因為少背了一個技巧，而是少了這套流程；做久了，看到新題目也知道從哪裡開始。題目都改寫成咖啡店的情境（訂單、飲料、價格、排隊的顧客、外送網格），並標出對應的 LeetCode 題號與英文題名。

建議的用法：一次做一課，先讀完、把頁面上的練習全部做到通過（隱藏測試會用固定的邊界案例、大量隨機案例比對標準答案，需要更好複雜度的題目還會用大資料量計時），再到 leetcode.com 搜尋那一課標出的題號，自己重寫一次當額外練習。第 6、11、18、23 課有不告訴你用哪個技巧的混合複習，第 27 課是限時的模擬面試。這門課排在 TypeScript 課之後，可以跟 Vue 課平行進行。

每一課都在頁面裡直接寫 TypeScript，按「檢查答案」自動判分。課裡標的 LeetCode 題號可以當作課後額外練習。
