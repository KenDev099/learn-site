JS、非同步與 TypeScript 學習地圖

前 12 課把 JavaScript 的執行機制講清楚：函式記得什麼（閉包與 this）、值和參考、原型與 class、錯誤處理、金額與大整數、日期時區與文字，再到 event loop、Promise、async/await、迭代器，以及最常讓線上系統出錯的逾時、取消、競態與重複送出。每個名詞第一次出現都會解釋，不假設你已經知道。

第 13 課開始是 TypeScript：從型別基礎一路到泛型、型別運算、類別、裝飾器與 tsconfig，最後用型別設計狀態與錯誤、驗證外部資料，做出一個能直接帶進 NestJS 課的訂單模組。每一課都在頁面裡動手寫：練習區是 VS Code 同款的編輯器（Monaco，內建 TypeScript 5.9.3），程式在瀏覽器的 Web Worker 裡執行；按「檢查答案」時，隱藏的執行測試和型別測試會擋下常見的錯誤寫法。每一題也用 TypeScript 7.0.2 檢查過，判分結果相同。全課程沿用 PostgreSQL 課的咖啡店資料。
