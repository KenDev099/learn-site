Learn · 後端主線 4

部署與維運 學習地圖

這門課把你寫好的後端送上線，並讓它在線上穩定地活著。先補伺服器基本功：shell、程序與訊號、網路、TLS、SSH 與 systemd；接著用 Docker 把咖啡店 API 裝進映像、用 Compose 一次啟動整套服務、用 Nginx 擋在最前面並水平擴展；再用 Git、GitHub Actions 自動檢查與部署，把資料庫 migration 安全地放進部署流程；然後上雲（AWS、IAM、基礎設施即程式碼）。最後一段是資深工程師最常被期待的能力：看懂 log、指標與 trace，訂 SLO 與告警，備份並真的還原過，處理事故並寫不究責的事後檢討。

練習在你的 Mac 上進行：每一課的起始檔案在 devops/practice/start/，第一次執行時會複製到 devops/practice/work/，你改 work/ 裡的檔案，再從 learn/ 執行 node check.mjs devops 課名，結果會回到課程頁面判分。大多數練習需要 Docker Desktop（第 1 課教你從終端機啟動它）；練習用到的服務一律只開在 127.0.0.1，不會暴露到區網。雲端課不需要 AWS 帳號，也不需要 GitHub 帳號；有帳號的話，課程會附上只讀的指令讓你看看自己的環境。

練習在你自己的電腦上做。需要 Node.js 24 和 Docker Desktop（終端機輸入 node -v、docker info 確認）。第一次開始前，在 learn 資料夾執行：

cd devops/practice && npm install

每一課的頁面會告訴你要改哪個檔案、要執行哪個指令；跑完測試切回課程頁就會自動判分。
