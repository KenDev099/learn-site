HTML、CSS 與網頁基礎 學習地圖

這門課補上前端工程師常常「會用但說不清楚」的那一層：HTML 的語意與表單、無障礙、CSS 的層疊與版面、現代 CSS、圖片與字型、瀏覽器怎麼把程式碼畫成畫面、效能怎麼量與怎麼驗收，以及讓搜尋引擎找得到、看得懂網站的 SEO。全課程用同一家咖啡店的公開網站當例子：首頁、菜單、門市資訊與「線上點餐」入口。每一課先示範不懂會出什麼事（例如 320px 手機上菜單被撐破、鍵盤使用者按不到點餐按鈕、首圖延遲載入讓 LCP 變慢、canonical 與 noindex 互相打架），再講怎麼做、為什麼。

練習大多在頁面裡完成：左邊改 HTML 與 CSS，右邊即時預覽；按下檢查後，隱藏測試會在 320、768、1280px 等寬度量測版面、讀取計算後的樣式、模擬 Tab 焦點順序、跑 axe-core 無障礙規則、解析 <head> 的 metadata 與 JSON-LD。測試也會擋下常見的「看起來對」的寫法：用 div 加 ARIA 假裝按鈕、拿掉焦點框、固定寬度讓手機橫向捲動、用 !important 硬蓋、用絕對定位排版、把關鍵字塞進 alt。效能與 SEO 的判斷題用真實格式的資料（Lighthouse 報告、CrUX 風格的欄位資料、路由表）在 TypeScript 練習區計算；最後的自動化驗收與期末專題在自己的電腦上用 Playwright 跑。

後半段是資深工程師的工作：用數字設定效能預算並防止回歸、把設計決策整理成 design tokens 與元件規格、寫不會時好時壞的 E2E 測試，最後交出一份咖啡店網站的驗收報告。跟其他課重疊的主題直接連過去：XSS 與 CSP 看認證課第 7 課、HTTP 快取看 Node 課第 15 課、SSR 與 hydration 看 Vue 課第 24 課、CI 看部署課第 15 課。

練習大多在頁面裡直接寫 HTML 和 CSS，右邊即時預覽、按「檢查答案」自動判分；少數需要真的瀏覽器或量測工具的題目會在本機跑，題目會寫清楚指令。
