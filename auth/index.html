Learn · 後端主線 3

認證、權限與資安 學習地圖

這門課回答後端最常被問、也最容易出事的三個問題：伺服器怎麼知道你是誰（認證）、知道之後你能做什麼、能看哪些資料（授權），以及攻擊者會從哪裡鑽進來（資安）。從編碼、雜湊、HMAC 這些密碼學基本工具開始，一路做到 Cookie 與 Session、CSRF、XSS、JWT、refresh token 輪替、OAuth 與 OpenID Connect（用 Google、LINE 登入）、TOTP 與 passkey、RBAC 與物件層級授權、多租戶、SSRF、資料加密，最後用 OWASP API Security Top 10、威脅建模與事故應變，練習資深工程師每天在做的判斷：哪裡有風險、先修哪個、出事時怎麼辦。除錯也是練習的一部分：cookie 為什麼被瀏覽器拒收、CORS 錯誤到底卡在哪一步、401 的真正原因是什麼。

練習方式：前 20 課與第 22～25 課在頁面裡的 TypeScript 練習區完成，用瀏覽器內建的 Web Crypto 親手做出密碼雜湊、JWT 簽章、PKCE、TOTP、passkey 驗證，隱藏測試會用真實的攻擊手法（竄改 token、alg: none、跨租戶 ID、DNS rebinding……）檢查你的程式。第 21 課和期末專題回到 NestJS 課的練習專案，在真的 API 上實作登入與權限、修補漏洞，用 E2E 測試攻擊自己的 API。全課程沿用咖啡店的資料：顧客、店員、店長、門市、訂單、集點卡。

大部分練習直接在頁面上寫 TypeScript；第 21、26 課在 NestJS 課的練習專案裡做（要先完成 NestJS 課的環境設定）。
