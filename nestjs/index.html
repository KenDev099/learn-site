NestJS 學習地圖

用 NestJS 12 寫出真正能上線的咖啡店 API。先從 controller、provider、module 這些骨架開始，搞懂一個請求從進來到回應要經過哪些關卡（middleware、guard、pipe、interceptor、exception filter），而且每一步都寫測試；接著用 Docker 跑起 PostgreSQL 與 Redis、用 Prisma 7 接上資料庫，處理關聯、交易、並發與查詢效能；再加入 Redis 快取、BullMQ 佇列與 transactional outbox、排程、檔案上傳與 webhook；最後學上線之後的事：結構化日誌、健康檢查、優雅關機、除錯方法與架構決策。

這門課在你自己的 Mac 上練習：每一課是 learn/nestjs/practice/work/ 裡的一個小型 NestJS 專案，改完程式在 learn/ 執行 node check.mjs nestjs <課程> 自動判分。資料庫與 Redis 用 Docker Compose 啟動，第 12 課會從零說明。判分不只看功能：會用 20 個同時進來的請求測超賣、檢查錯誤訊息有沒有外洩、實際 build 再啟動一次，抓出「測試會過、正式環境卻壞掉」的問題；寫測試的練習則會拿幾個故意改壞的版本，檢查你的測試抓不抓得到 bug。

版本：NestJS 12.3、Prisma 7.10（npm 上 prisma 的 latest 標籤是 8.0 預覽版；Prisma 官網網址沒有 /orm/v7/ 的文件頁也是 8.0 的寫法，指令完全不同，請照課程鎖定的版本並看 v7 文件）、TypeScript 6.0（Nest CLI 還不支援 7.0）、Vitest 5、PostgreSQL 18、Redis 8。前置課程：PostgreSQL（含第 27–39 課的資深單元：keyset 分頁、隔離等級與重試、SKIP LOCKED 與 outbox、零停機 migration）、JS 與 TypeScript、Node.js 核心；登入與權限在下一門「認證、權限與資安」。

練習在你自己的電腦上做。需要 Node.js 24 和 Docker Desktop（終端機輸入 node -v、docker info 確認）。第一次開始前，在 learn 資料夾執行：

cd nestjs/practice && npm install

每一課的頁面會告訴你要改哪個檔案、要執行哪個指令；跑完測試切回課程頁就會自動判分。
